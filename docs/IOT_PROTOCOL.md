# EstateIQ Telemetry Protocol & Payload Specification

This document defines the canonical JSON telemetry envelope (`schema_version: "1.0"`), authentication contracts, and Server-Sent Events (SSE) streaming format utilized by the **EstateIQ Facility Decision Intelligence Platform**.

---

## 2. Field Definitions & Standards

| Field Name | Type | Mandatory? | Description |
|---|---|---|---|
| `schema_version` | String | Yes | Protocol version. Current: `"1.0"`. |
| `message_id` | String | Yes | Unique UUID or deterministic identifier per packet. |
| `device_id` | String | Yes | Unique ID of originating edge device or simulator. |
| `facility_id` | String | Yes | Campus or facility identifier (e.g. `FAC_GEC_CAMPUS`). |
| `building_id` | String | Yes | Specific building zone (e.g. `BLOCK_B`, `CANTEEN`). |
| `source_type` | String | Yes | Data provenance category: `"hardware"`, `"simulated_iot"`, or `"csv_import"`. |
| `is_verified_hardware`| Boolean | Yes | `true` if generated by physical sensors/gateway; `false` if simulated. |
| `event_timestamp` | String | Yes | ISO 8601 UTC timestamp of physical observation. |
| `sent_timestamp` | String | No | ISO 8601 UTC timestamp when packet was dispatched. |
| `sequence_number` | Integer | No | Strictly increasing counter to detect dropped packets. |
| `metrics` | Array | Yes | Non-empty list of metric value objects. |

### Metric Object Schema
- `metric`: Canonical metric name (e.g. `active_power`, `energy_kwh`, `flow_rate_lpm`, `pm25`, `waste_fill_pct`).
- `value`: Numeric scalar measurement.
- `unit`: Recognized physical unit (e.g. `kW`, `kWh`, `V`, `A`, `L/min`, `L`, `µg/m³`, `%`).
- `quality`: Data quality flag (`"good"`, `"suspect"`, `"bad"`, `"interpolated"`).

## 4. Ingestion Authentication & Headers

Physical edge gateways transmit their provisioned gateway secret via HTTP headers:

```http
POST /api/v1/iot/telemetry HTTP/1.1
Host: 127.0.0.1:8000
Content-Type: application/json
X-Gateway-Key: ESTATEIQ-GATEWAY-SECRET-KEY
```

Supported authentication headers:
- `X-Gateway-Key`: Matches configured `GATEWAY_API_KEY` (default: `ESTATEIQ-GATEWAY-SECRET-KEY`).
- `X-API-Key`: Alternative API key header.
- `Authorization: Bearer <jwt_token>`: Role-based user JWT token.

## 5. Server-Sent Events (SSE) Streaming Format

The streaming endpoint (`GET /api/v1/iot/telemetry/stream`) dispatches real-time SSE frames formatted as JSON:

```text
data: {"device_id": "ESP32_EDGE_GATEWAY_01", "building_id": "BLOCK_B", "source_type": "hardware", "is_verified_hardware": true, "timestamp": "2026-11-07T15:30:00.000000Z", "metrics": {"active_power": 45.2, "energy_kwh": 1284.6, "power_factor": 0.94, "flow_rate_lpm": 14.5}}

```

Clients can parse the `data:` payload in real-time without continuous REST polling.
