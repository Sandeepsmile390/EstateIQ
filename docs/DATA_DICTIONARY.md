# 📖 Data Dictionary & Catalog

Dataset catalog and Canonical Telemetry Specification for **EstateIQ Smart Facility & Campus Platform**.

---

## 1. ⚡ EstateIQ Canonical Telemetry Specification

All real edge nodes (ESP32, Modbus adapters, IoT gateways) and simulators adhere to the canonical telemetry schema defined in `src/data/telemetry_schema.py`.

### Telemetry Envelope Schema

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `schema_version` | String | Yes | Canonical envelope version (`"1.0"`) |
| `message_id` | String | Yes | Globally unique message UUID or deterministic hash for idempotency |
| `source_type` | Enum | Yes | `real_sensor`, `simulated_iot`, `synthetic`, `derived`, `predicted` |
| `event_timestamp` | String (ISO8601) | Yes | UTC timestamp when the sample was physically captured |
| `sent_timestamp` | String (ISO8601) | Yes | UTC timestamp when the message was transmitted |
| `sequence_number` | Integer | Yes | Monotonically increasing sequence counter from edge device |
| `device_id` | String | Yes | Unique identifier of the meter/sensor (e.g., `METER_ELEC_01`) |
| `gateway_id` | String | No | Edge gateway or microcontroller ID (e.g., `ESP32_EDGE_GW_01`) |
| `simulator_id` | String | No | Present only when stream originates from an IoT simulator |
| `facility_id` | String | Yes | Facility identifier (e.g., `FAC_GEC_CAMPUS`) |
| `building_id` | String | Yes | Building name or code (e.g., `Block B Hostel`) |
| `metrics` | Array | Yes | List of canonical metric objects |
| `quality` | Object | No | Device diagnostics (e.g., `status: "GOOD"`, `last_meter_read_ms: 1240`) |

### Canonical Metrics Dictionary

#### Electricity Metrics
| Canonical Metric Name | Unit | Type | Physical Bounds | Description |
| :--- | :--- | :--- | :--- | :--- |
| `cumulative_energy_kwh` | kWh | Cumulative Counter | $\ge 0$ | Monotonic imported active energy from Modbus meter register |
| `active_power_kw` | kW | Instantaneous Rate | $0 - 5000$ | Active power demand across monitored phases |
| `voltage_v` | V | Instantaneous | $80 - 480$ | RMS line-to-neutral or line-to-line AC voltage |
| `current_a` | A | Instantaneous | $0 - 2000$ | RMS active current draw |
| `power_factor` | ratio | Dimensionless | $-1.00 \text{ to } 1.00$ | Total power factor (lagging/leading) |
| `frequency_hz` | Hz | Instantaneous | $40 - 70$ | Grid line frequency (nominal 50 Hz in India) |
| `maximum_demand_kw` | kW | Peak Window | $0 - 5000$ | 15-minute rolling maximum demand |
| `thd_voltage_pct` | % | Harmonic Distortion | $0 - 100$ | Total harmonic distortion of voltage |
| `energy_kwh` | kWh | Interval Delta | $\ge 0$ | Derived consumption delta across ingestion interval |

#### Water Metrics
| Canonical Metric Name | Unit | Type | Physical Bounds | Description |
| :--- | :--- | :--- | :--- | :--- |
| `water_flow_lmin` | L/min | Instantaneous Rate | $0 - 2000$ | Volumetric flow rate from pulse counter or magnetic flowmeter |
| `cumulative_water_m3` | m³ | Cumulative Counter | $\ge 0$ | Monotonic cumulative total water consumed |
| `water_consumption_liters`| Liters | Interval Delta | $\ge 0$ | Derived volumetric consumption over sample interval |
| `water_pressure_bar` | bar | Instantaneous | $0 - 25$ | Hydraulic water line pressure |
| `tank_level_pct` | % | Level | $0.0 - 100.0$ | Overhead storage tank fill percentage |
| `tank_distance_cm` | cm | Raw Distance | $10 - 500$ | Ultrasonic echo distance from sensor to water surface |

#### Provenance Types & Display Badges
| Provenance Code | Description | Dashboard Display Badge |
| :--- | :--- | :--- |
| `real_sensor` | Physically wired Modbus or pulse sensor read by ESP32 edge node | `[REAL SENSOR]` (Green `#00D09C`) |
| `simulated_iot` | Synthetic telemetry streaming from interactive campus simulator | `[SIMULATED IoT]` (Amber `#F59E0B`) |
| `synthetic` | Historical baseline training dataset generated by statistical models | `[SYNTHETIC DATA]` (Teal `#2DD4BF`) |
| `derived` | Anomaly score, interval consumption, or fused state calculation | `[DERIVED METRIC]` (Blue `#38BDF8`) |
| `predicted` | CatBoost/ML regression forecast or DIF decision attribution | `[ML FORECAST]` (Gold `#D97706`) |

## 2. 📊 Major Database Tables (`facility.db`)

### 1. `energy_readings`
| Column | Data Type | Unit | Range | Description |
| :--- | :--- | :--- | :--- | :--- |
| `timestamp` | DATETIME | ISO8601 | 2026-01-01 to 2026-06-29 | 15-minute interval timestamp |
| `building_id` | TEXT | ID | BLD001 to BLD010 | Campus building identifier |
| `electricity_kwh` | FLOAT | kWh | $\ge 0$ | Total 15-min electricity consumption |
| `hvac_kwh` | FLOAT | kWh | $\ge 0$ | HVAC sub-meter consumption |
| `power_factor` | FLOAT | ratio | 0.70 to 1.00 | Electrical power factor |
| `renewable_generation_kwh` | FLOAT | kWh | $\ge 0$ | Rooftop solar energy generated |
| `grid_import_kwh` | FLOAT | kWh | $\ge 0$ | Net electricity drawn from grid |

### 2. `water_readings`
| Column | Data Type | Unit | Range | Description |
| :--- | :--- | :--- | :--- | :--- |
| `water_consumption_liters` | FLOAT | Liters | $\ge 0$ | Total 15-min water consumption |
| `water_flow_rate_lpm` | FLOAT | LPM | $\ge 0$ | Water flow rate in Liters Per Minute |
| `tank_level_percent` | FLOAT | % | 0.0 to 100.0 | Overhead storage tank level |

### 3. `waste_readings`
| Column | Data Type | Unit | Range | Description |
| :--- | :--- | :--- | :--- | :--- |
| `bin_id` | TEXT | ID | BIN_01 to BIN_32 | Smart bin identifier |
| `fill_level_percent` | FLOAT | % | 0.0 to 100.0 | Ultrasonic fill level percentage |
| `overflow_within_2h` | INT | binary | 0 or 1 | Target: Bin overflow within 2 hours |
| `overflow_within_4h` | INT | binary | 0 or 1 | Target: Bin overflow within 4 hours |

### 4. `air_quality_readings`
| Column | Data Type | Unit | Range | Description |
| :--- | :--- | :--- | :--- | :--- |
| `pm25` | FLOAT | $\mu g/m^3$ | $\ge 0$ | Particulate matter PM2.5 concentration |
| `pm10` | FLOAT | $\mu g/m^3$ | $\ge 0$ | Particulate matter PM10 concentration |
| `aqi` | FLOAT | index | 0 to 500 | Indian CPCB Air Quality Index proxy |

### 5. `equipment_sensor_readings`
| Column | Data Type | Unit | Range | Description |
| :--- | :--- | :--- | :--- | :--- |
| `asset_id` | TEXT | ID | AST_CHILLER_01 ... | Asset identifier |
| `temperature_c` | FLOAT | °C | 20.0 to 110.0 | Operating temperature |
| `vibration_mm_s` | FLOAT | mm/s | 0.0 to 15.0 | Vibration amplitude |
| `maintenance_risk_score` | FLOAT | score | 0.0 to 1.0 | Predictive maintenance risk score |
